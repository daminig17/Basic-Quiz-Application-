v📚 Basic Quiz Application (JavaScript)
This is a simple and beginner-friendly web-based quiz application built using HTML, CSS, and JavaScript. It presents users with a series of multiple-choice questions and tracks their score based on correct answers. At the end of the quiz, users can view their results.

🛠 Features
Displays one question at a time with multiple answer choices

Highlights correct and incorrect answers

Tracks score in real-time

Shows final score at the end of the quiz

Responsive design for mobile and desktop

🚀 Technologies Used
HTML for structure

CSS for styling

JavaScript for logic and interactivity
